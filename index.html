Secure OAuth broker setup

Why a broker is required, and a minimal reference implementation.

Do not put a client secret in this HTML file. GitHub’s token endpoint requires a client secret, does not support CORS, and cannot be called safely from a browser. The broker is a tiny server-side function that holds the secret and performs the exchange.

1. Create a GitHub OAuth App

  1. GitHub → Settings → Developer settings → OAuth Apps → New OAuth App.
  2. Set the callback URL to the redirect URI shown in this app’s settings.
  3. Copy the Client ID into this app. Keep the Client Secret for the broker environment only.
  4. Enable the OAuth scope required: public_repo for public sites, or repo if you need private repositories.

2. Deploy the broker

Reference Cloudflare Worker. Set GITHUB_CLIENT_ID, GITHUB_CLIENT_SECRET, and a comma-separated ALLOWED_ORIGINS allowlist.

3. Broker contract

            

              
Request: POST {brokerUrl} with JSON { code, code_verifier, redirect_uri, client_id }.

              
Response: 200 with JSON { access_token, token_type, scope } and CORS headers for this origin.

              
Never: log the authorization code or token, or return the client secret.
